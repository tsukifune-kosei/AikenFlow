# SimpleVault Assurance Artefacts

Generated by AikenFlow from the protocol IR.

These artefacts support review, testing, and audit preparation. They are not formal proofs and do not use repository outlines or agent-context files as protocol semantics.

## Files

- `state-graph.mmd`: Mermaid state machine graph.
- `topology.json`: Machine-readable transition topology.
- `coverage.json`: Machine-readable constraint and invariant coverage summary.
- `invariant-matrix.md`: Invariant-to-transition review matrix.
- `adversarial-cases.md`: Generated negative-case checklist.
- `tests/adversarial.spec.ts`: TypeScript test stubs for emulator integration.
- `AUDIT.md`: Human-readable protocol audit artefact.
