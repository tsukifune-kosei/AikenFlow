# SimpleVault Off-chain Builders

Generated by AikenFlow from the protocol IR.

These files define a structural transaction-builder adapter. Replace the structural types in `src/types.ts` with real Lucid, Mesh, Blaze, or project-local imports during integration.

Repository outlines and agent-context files are not used as compiler semantics.

## Layout

- `src/types.ts` contains structural SDK-compatible types.
- `src/index.ts` contains one builder function per transition.

## Asset Handling

- Explicit `outputs[].value` maps become `payToContract` asset maps.
- State-transition outputs without `value` carry assets from the consumed UTxOs when there is a consumed input to carry from.
- Creation outputs without `value` fail at runtime until the protocol spec declares explicit assets.

## Parameter Naming

- Self-transition outputs use `next<State>Address` and `next<State>Datum` parameters when input and output state names would otherwise collide.

## SDK Requirements

- Transitions with reference inputs require transaction-builder `readFrom` support.
- Transitions with mint or burn effects require transaction-builder `mintAssets` support.
- Missing required SDK methods fail at runtime instead of silently skipping protocol actions.
